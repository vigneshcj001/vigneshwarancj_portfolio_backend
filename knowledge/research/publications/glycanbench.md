# GlycanBench: a unified resource for working with glycans

Unified glycoinformatics web server and Python package with 20 tools. Includes an MPNN trained on 1,344 curated glycans after correcting 12 contradictory labels, on-demand conformers, GLYSUM alignment, network visualisation, and GlycomicsChat.
